# Reports

This folder contains the detailed technical report for the Lokoja flood project.

For a shorter report written in plain language, start with [`../docs/PROJECT_REPORT.md`](../docs/PROJECT_REPORT.md). It explains the reason for rebuilding the hazard classes, the historical validation, the difference between hazard and risk, and the main limits of the model.

The technical report is useful when you need the fuller methodology, tables, sensitivity tests and validation detail.
